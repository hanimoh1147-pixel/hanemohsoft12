# موقع هاني سوفت

## تشغيل الموقع
1. فك ضغط الملف `hany_soft_website.zip`.
2. افتح `index.html` في متصفح حديث.
3. قبل النشر، افتح `script.js` وعدّل `WHATSAPP_NUMBER` إلى رقم واتساب الخاص بك بصيغة دولية بدون `+` أو مسافات.
4. عدّل قائمة `SERVICES` في `script.js` لتضع خدماتك وأسعارك الحقيقية.
5. اختبر الروابط والنموذج من الهاتف والكمبيوتر.

## نشر مجاني عبر GitHub Pages
1. أنشئ حساباً في GitHub إن لم يكن لديك حساب.
2. أنشئ مستودعاً جديداً (Repository)، مثلاً `hany-soft`.
3. ارفع الملفات الثلاثة `index.html` و`style.css` و`script.js` إلى جذر المستودع.
4. افتح Settings ثم Pages.
5. في Build and deployment اختر Deploy from a branch، ثم الفرع `main` والمجلد `/ (root)` واضغط Save.
6. انتظر حتى يظهر رابط الموقع في صفحة Pages. قد يستغرق النشر عدة دقائق.

## مهم بخصوص لوحة الإدارة
هذا نموذج واجهة أمامية فقط. الطلبات التي تُحفظ في لوحة الإدارة مخزنة في `localStorage` في المتصفح الحالي، ولا تنتقل بين الأجهزة، وقد تختفي عند مسح بيانات المتصفح. إرسال النموذج يفتح واتساب برسالة جاهزة، ولا يمكن للموقع معرفة ما إذا أُرسلت الرسالة فعلاً.
للوحة إدارة حقيقية متعددة المستخدمين تحتاج إلى خادم وقاعدة بيانات وتسجيل دخول وصلاحيات. لا تضع كلمات مرور أو مفاتيح سرية في JavaScript.
